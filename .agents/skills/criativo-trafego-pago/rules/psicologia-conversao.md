# Psicologia de Conversao para Criativos

## Gatilhos Mentais Aplicados a Ads

### 1. Escassez
Quando algo e limitado, o desejo aumenta.

**Aplicacao no criativo:**
- Contador regressivo visual
- "Ultimas X unidades" com numero diminuindo
- Badge "ESGOTANDO" animado
- Barra de estoque diminuindo

```
Copy: "So restam 23 vagas - e nao vamos reabrir"
Visual: Barra de progresso quase cheia + numero diminuindo
```

### 2. Urgencia
Pressao temporal acelera a decisao.

**Aplicacao no criativo:**
- Timer contando regressivamente
- "Oferta valida ate hoje 23:59"
- Flash vermelho pulsando
- Data/hora expirando na tela

```
Copy: "Esse preco acaba em 2 horas"
Visual: Relogio animado + cor vermelha pulsando
```

### 3. Prova Social
Pessoas seguem o comportamento de outras.

**Aplicacao no criativo:**
- Numeros grandes animados ("10.000+ clientes")
- Screenshots de depoimentos
- Notificacoes fake-live ("Maria acabou de comprar")
- Rating com estrelas animadas
- Logos de empresas clientes

```
Copy: "Junte-se a mais de 10.000 pessoas que ja transformaram..."
Visual: Contador subindo de 0 ate 10.000 com spring animation
```

### 4. Autoridade
Pessoas confiam em especialistas e marcas reconhecidas.

**Aplicacao no criativo:**
- Selo "Aprovado por [autoridade]"
- Mencao a universidades, certificacoes
- "Recomendado por [influencer]"
- Aparicao do expert em video

```
Copy: "Metodo validado por Harvard Business Review"
Visual: Logo da instituicao + selo de aprovacao
```

### 5. Reciprocidade
Quando alguem nos da algo, sentimos vontade de retribuir.

**Aplicacao no criativo:**
- Ofereca valor gratis primeiro (checklist, aula, template)
- "Presente gratis: [material de valor]"
- Lead magnet atrativo

```
Copy: "Baixe gratis: O guia completo de [assunto]"
Visual: Mockup 3D do material + badge "GRATIS"
```

### 6. Ancoragem
O primeiro numero que vemos influencia nossa percepcao.

**Aplicacao no criativo:**
- Mostre o preco original ANTES do desconto
- "De R$997 por apenas R$297"
- Risco no preco antigo com animacao
- Comparacao com alternativas mais caras

```
Copy: "De R$1.997 → Por apenas 12x de R$49,70"
Visual: Preco antigo aparece, risco vermelho, preco novo surge com scale pop
```

### 7. Curiosity Gap (Lacuna de Curiosidade)
O cerebro precisa fechar loops abertos.

**Aplicacao no criativo:**
- "O segredo que ninguem te conta sobre..."
- Revelar parcialmente e pedir clique para ver o resto
- "O terceiro passo vai te surpreender"
- Borrar/censurar parte da informacao

```
Copy: "Descobri 3 coisas que fizeram meu faturamento 5x. A terceira..."
Visual: Itens 1 e 2 aparecem, item 3 borrado com "clique para ver"
```

### 8. Efeito IKEA (Envolvimento)
Pessoas valorizam mais o que ajudam a criar.

**Aplicacao no criativo:**
- Quizzes interativos
- "Responda: voce e tipo A ou tipo B?"
- Enquetes no video
- "Comenta X que eu te envio"

## Vieses Cognitivos em Criativos

### Efeito Halo
Se algo parece bom, assumimos que E bom.

**Aplicacao:** Design premium = produto premium. Invista em estetica.

### Aversao a Perda
Perder doi 2x mais que ganhar agrada.

**Aplicacao:** "Nao perca essa oportunidade" > "Ganhe essa oportunidade"

### Efeito Bandwagon
Quanto mais gente faz, mais queremos fazer.

**Aplicacao:** "Mais de 50.000 downloads essa semana"

### Viés de Confirmacao
Pessoas buscam informacoes que confirmam suas crencas.

**Aplicacao:** Comece validando o que o publico ja acredita, depois redirecione.

## Estrutura Emocional do Criativo

O criativo ideal segue uma curva emocional:

```
Emocao
  ^
  |        Solucao        CTA
  |       /  \           / \
  |      /    \    Prova/   \
  |     /      \  /         |
  |    /        \/          |
  |   /                     |
  |  / Hook                 |
  | /                       |
  |/________________________|___> Tempo
  0   3s   8s  15s  25s  30s

Hook:    Curiosidade/Choque (alta)
Problema: Dor/Frustacao (baixa)
Solucao:  Esperanca/Alivio (alta)
Prova:    Confianca (media-alta)
CTA:      Urgencia/Desejo (alta)
```

### Emocoes por Fase

| Fase | Emocao alvo | Tecnica visual |
|------|------------|----------------|
| Hook | Surpresa, Curiosidade | Movimento rapido, cor vibrante, zoom |
| Problema | Frustracao, Identificacao | Tons escuros, camera lenta, expressoes |
| Solucao | Esperanca, Alivio | Cores claras, musica upbeat, revelacao |
| Prova | Confianca, Validacao | Depoimentos, numeros, badges |
| CTA | Urgencia, Desejo | Vermelho/laranja, countdown, escassez |

## Cores e Emocoes em Ads

| Cor | Emocao | Uso em ads |
|-----|--------|-----------|
| Vermelho | Urgencia, energia, paixao | CTAs, descontos, alertas |
| Laranja | Entusiasmo, acao, calor | Botoes, ofertas, badges |
| Amarelo | Atencao, otimismo, alerta | Highlights, destaques |
| Verde | Confianca, sucesso, dinheiro | Provas, resultados, eco |
| Azul | Confianca, seguranca, calma | Tech, saude, financas |
| Roxo | Premium, criatividade, luxo | High-ticket, premium |
| Rosa | Feminino, cuidado, juventude | Beauty, moda, wellness |
| Preto | Sofisticacao, poder, exclusivo | Luxo, premium, tech |
| Branco | Limpeza, simplicidade, pureza | Minimalismo, saude |

### Combinacoes de alta conversao:
- **Vermelho + Preto**: Urgencia premium
- **Azul + Branco**: Confianca limpa
- **Laranja + Escuro**: Energia com contraste
- **Verde + Branco**: Resultado positivo
- **Gradiente neon**: TikTok/GenZ appeal

## Checklist de Psicologia por Criativo

- [ ] Pelo menos 2 gatilhos mentais presentes?
- [ ] Curva emocional seguida (hook → dor → solucao → prova → CTA)?
- [ ] Cores alinhadas com a emocao desejada?
- [ ] Prova social visivel?
- [ ] Escassez/urgencia no CTA?
- [ ] Ancoragem de preco (se aplicavel)?
- [ ] Loop de curiosidade para gerar clique?
